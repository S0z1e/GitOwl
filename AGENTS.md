    ## Agent skills

### Issue tracker

Issues for this repository are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Issue `Status:` values use the canonical roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`, plus `complete` for issues that are done. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context `CONTEXT.md` and root `docs/adr/`. See `docs/agents/domain.md`.
